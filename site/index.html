An AI agent for your browser that never sees your data.

Pawtrol is a Chrome extension. Tell it what to do on a page, like “fill this form”, and it clicks and types for you. Before any page text or screenshot leaves your computer, it hides your passwords, ID numbers, card numbers and faces. The AI works with placeholders, and Pawtrol types the real values in locally.

The model plans the task. It never needs the real values.

To fill an Aadhaar field, the AI only has to know there is an Aadhaar number and where it goes. Pawtrol keeps the number and types it in itself.

On your device

1Find what’s sensitive

Pawtrol reads the page and flags passwords, Aadhaar and PAN numbers, card numbers, emails, phone numbers and names. ID numbers are checked with their checksums (Verhoeff for Aadhaar, Luhn for cards), so random digits aren’t mistaken for IDs.

On your device

2Swap them for tokens

Each value becomes a placeholder like <ID_1>. The real values stay in a vault inside the extension, which is wiped after every task. Passwords are withheld completely.

In the cloud

3The model plans with tokens

The AI sees the page’s layout and the tokens, then replies with actions: type <ID_1> into “Aadhaar”, click “Submit”. If a page tries to trick it into asking for a token Pawtrol never issued, the request is refused.

On your device

4Pawtrol fills in the real values

The tokens are turned back into real values inside your browser and typed into the page. Before anything risky, like submitting, sending or paying, Pawtrol stops and asks you.

Screenshots get the same treatment, and a second check.

Your choice

Set it up in about two minutes.

Pawtrol isn’t on the Chrome Web Store yet, so you load it yourself. It works in Chrome on Windows, macOS and Linux.

  1. Download and unzip

    Unzip pawtrol-extension.zip into a folder you’ll keep, like Documents/Pawtrol. Chrome loads it from there, so don’t delete it.

    Download ZIP

  2. Open Chrome’s extensions page

    Paste this into the address bar, then turn on Developer mode in the top-right corner.

    chrome://extensions

  3. Load unpacked

    Click Load unpacked and choose the unzipped folder (the one with manifest.json in it). Pin Pawtrol from the puzzle-piece menu so it’s one click away.

  4. Pick your model

    Open Pawtrol’s settings, choose a provider and paste your API key. For a fully offline setup, choose Ollama. It needs no key.

  5. Give it a task

    Click the Pawtrol icon to open the side panel, or press Alt + Shift + P on any page for the floating launcher. Try “Scan this page for personal data”.

Questions

Is Pawtrol free?

Yes. You only pay your model provider, if they charge. Several have free tiers, and Ollama runs free on your own machine.

Does my data go to a Pawtrol server?

There is no Pawtrol server. The extension talks directly to the provider you choose, and only after redaction. Your API key and settings stay in Chrome’s local storage.

What if Pawtrol misses something?

Several layers overlap: detection on the page text, vision models on screenshots, a re-check of the masked image, and a final scan of every outgoing request that blocks any ID number still present. If a check can’t run, Pawtrol drops the screenshot instead of sending it unchecked.

Can it do anything without asking me?

It can read, scroll, click and type. Anything that commits you, like submitting, sending or paying, waits for your approval. You can stop a task at any time.

Which browsers does it work in?

Google Chrome, version 120 or newer, because Pawtrol lives in Chrome’s side panel. Other browsers aren’t supported yet.

Why is the download so big?

It includes the OCR engine and the small vision models that run on your device, so screenshots never need a server to be cleaned.
